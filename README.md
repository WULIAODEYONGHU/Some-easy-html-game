# doss直聘模拟器

> 一个模仿招聘 App 的沙雕小游戏：20 个薪资高到离谱的虚构岗位，两种角色任选，HR 和应聘者都由内置规则引擎实时扮演。

**在线试玩**：https://wuliaodeyonghu.github.io/Some-easy-html-game/
（也可直接下载 `standalone/zhipin-simulator.html` 存到本地，双击用浏览器打开就能玩，无需联网）

---

## 玩法

### 🧑‍💼 应聘者模式
你找工作。打招呼、发简历、约面试；面试里可以随便刁难 HR、随便放鸽子。
HR 会嘴硬，但嘴硬一秒后就百依百顺，只会用加薪挽留你。最后从一堆 Offer 里挑一个入职，游戏结束。

### 🏢 HR 模式
反过来你当招聘官。系统生成一批虚拟简历（不够还能再收），你负责筛选、约面试、百般刁难，应聘者只能百依百顺。
从几十号人里选定最终录用，游戏结束。

### 💬 面试里可以这么玩
| 打法 | 例子 |
|---|---|
| 谈薪 | 「给我开 165K 行不行」—— HR 真的会跟你来回还价 |
| 施压 | 「我手上还有一家」—— HR 自己把价抬上去 |
| 试探 | 加班吗？双休吗？年终几月发？ |
| 摆烂 | 放鸽子、嘴硬到底 |

## 特性

- **20 个虚构岗位**：首席摸鱼战略官、带薪如厕体验师、老板画饼识别与粉碎专家、猫主子情绪翻译官……顶格月薪 300K，纯属虚构
- **成就系统**：9 个结局称号（鸽王之王 👑 / 职场嘴强王者 😤 / 薪资谈判艺术家 📈 / Offer 收割机 💰 / 躺赢打工人 🛋️）+ 10 个隐藏成就
- **完全离线**：纯前端单页，无后端、无 API Key、不联网、不登录
- **手机适配**：全屏沉浸、输入键盘自动跟随、顶部安全区适配

## 本地运行

```bash
# 方式一：直接打开（最简单）
双击 index.html

# 方式二：起个本地服务（推荐，行为更接近线上）
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 目录结构

```
.
├── index.html                      # 页面骨架，引用下方资源（相对路径）
├── assets/
│   ├── style.css                   # 样式
│   └── app.js                      # 全部游戏逻辑（IIFE，无依赖）
├── standalone/
│   └── zhipin-simulator.html       # 单文件版：HTML+CSS+JS 全内联，可单独下载离线玩
├── build-github.js                 # 从单文件版生成本仓库结构的构建脚本
├── LICENSE                         # MIT
└── README.md
```

> `standalone/` 是便于分发用的单文件副本；日常开发改 `assets/` 里的文件即可，改完重新跑一次 `node build-github.js` 会同步生成单文件版。

## 关于存档

存档写在浏览器 `localStorage`（不可用时自动降级到 cookie），**按域名隔离**：
本地 `file://`、GitHub Pages、其他站点之间的进度互不相通，换域名等于新档（成就跨局累计，重开一局不会清空）。

## 数据来源

- 岗位、公司、HR、应聘者、对话**全部为虚构内容**，不对应任何真实企业或个人
- HR 与应聘者的对路由**本地规则引擎**生成，未接入任何大模型或外部服务
- 界面风格为对招聘类 App 的戏仿（parody），**与任何真实产品无隶属、授权或合作关系**
